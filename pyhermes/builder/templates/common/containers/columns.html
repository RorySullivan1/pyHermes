{# MULTI-COLUMN CONTAINER One template for every split, two columns or three. The eight per-ratio files this replaced were byte-identical apart from a Jinja comment and the numbers — which is what made the frame an assumption spread across eight files rather than a value the builder owns. Widths arrive computed: pyhermes.builder.sizing.column_layout() splits the frame's content width by the ratio's own weights, floors each column and distributes the remainder outside-in, then gives each column the padding its width earns. The MSO ghost table and the inline-block table read the *same* number, because there is now only one number to read. The band is wrapped in a cell that insets it by frame.pad_x, so its text starts where a full-width section's text starts and where this section's own heading starts. That cell also zeroes font-size and line-height: the columns are inline-blocks, so the newline between two of them would otherwise render as a space, and 616px of columns plus that space no longer fits in 616px of content width. The column cells set both properties themselves, so nothing inherits the zero.
