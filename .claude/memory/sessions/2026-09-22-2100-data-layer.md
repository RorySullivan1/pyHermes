## Decisions and why
- **No `DataTable.from_frame` / `ChartBlock.from_figure`.** #179 and #180 asked for both the
  classmethods and a purity test that `svc/builder` never imports `svc.data`; the two cannot
  both hold. The purity test stayed (it is what proves the extras optional); entry points are
  functions in `svc.data`, `svc.pdf.render_pdf`'s shape. Appending the classmethod fails the
  purity test by name.
- **`tight=True` is opt-in**, against #180's text, because a tight bbox crops and so breaks the
  exact `width × scale` pixel width the issue's own done-when pins.
- **Tone is not a fifth colour exception.** It carries no hex; a hex passed as a tone raises and
  names `color`. Precedence: subhead → explicit colour → tone → the column's kind.
- **A figure shown as zero is neutral** whatever its unrounded sign (`tone_of(value, fmt)` asks
  `formats.displays_zero`), so the string and its colour cannot disagree.

## What proved it
- **Goldens, not assertions.** Classic's `semantic.positive`/`negative` are exactly the hexes
  `kitchen_sink` passed by hand, so moving its KPI strip and two table rows to tones left every
  golden byte-identical. One toned cell in `slate_theme` moved one line, `#5A6068` → slate's
  `#A8514E` — the first render of `semantic.negative` in the gallery. Screenshot confirms.
- **Perturbations, each failing by name:** banker's rounding (6 cases); dropping the template's
  tone branch (6); tone ahead of colour (1); a lazy `svc.data` import in `components.py` (1).
- **Both install shapes.** With both extras: 2176 passed, mypy clean. In a fresh `[dev]`-only
  venv (no pandas, matplotlib or numpy): adapter modules skip naming their extras, the 12
  purity/missing-backend tests pass, 2091 passed, mypy clean.

## Gotchas & dead ends
- **`pytest | tail -1 && git commit` committed a red suite** — `tail` exits 0. A prose-budget
  failure (`table_from_frame` docstring, 19 lines against 18) went into `442a948`; amended to
  `f593595` before any push. Gate commits on `set -o pipefail`.
- **`Cell`'s docstring is baselined at 36 lines** and the baseline may only shrink, so the tone's
  argument went to `data-table.md`, not the class.
- **Jinja's subscript falls back to getattr**, so `theme.semantic[cell.tone]` works on the
  `SemanticColors` dataclass with no filter, and `theme.semantic['neutral']` keeps the untoned
  card byte-identical.
- **`savefig` embeds the matplotlib version** in the PNG's `Software` chunk, which would change
  every chart's content-addressed cid on upgrade; `metadata={"Software": None}` drops it.
