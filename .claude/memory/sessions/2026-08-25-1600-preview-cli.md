## Decisions

- **Compose, never reimplement.** A test asserts the written HTML equals `Email.render()`
  byte for byte — a second rendering path would make the tool worse than useless.
- **A gap goes back into the module that owns it.** `capture_gallery()` could only screenshot
  registry names, and *a user's draft never is one*. Hence `capture_emails()`, keyed by email
  rather than fixture name. This was #61's own instruction and it fired on the first real use.
  Side benefit: emails now render *before* the browser launches, so a build failure costs no
  browser start.
- **Split the target on the LAST colon** so a Windows drive letter is not the separator.
  Output name is `{module_stem}-{callable}` so two files both defining `build()` do not
  collide in `output/`.
- **Accept `Email` OR `EmailBuilder`** — both are public API; a caller should not have to
  remember which their own function returns.
- **Exit codes are the interface**: 0 clean, 1 lint errors, 2 unbuildable/unresolvable.
  Warnings alone do not fail. That is what lets it run in a hook.
- **A missing browser is a skip, not a failure** ([qa] is optional by design) — and a test
  asserts the skip does *not* mask a lint error, since the flags are independent.
- **`EmailBuilderError` raised while IMPORTING a target module propagates as itself**, rather
  than being flattened into "failed to import": the builder names the field, and that message
  is the useful one. Everything else during import becomes a `PreviewError`.
- **No console script**, inheriting #57: `qa/` is outside the wheel because the gallery is
  test data, so an installed entry point would contradict that.

## Gotchas

- `qa/preview.py` imports `qa.screenshots` at module level, which is safe without the extra
  only because playwright is imported lazily inside `_load_playwright()`. Keep it that way or
  the core browser-free suite breaks at collection.
- Re-verified in `scratchpad/devonly` (the `[dev]`-only venv) before pushing — that is the
  only faithful local stand-in for CI's `check` job, and it is what caught the mypy/playwright
  failure last time.
