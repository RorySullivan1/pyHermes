## Decisions and why
- **Outlook and `colspan` is unverified here.** The stub asserted the Word engine renders it;
  neither the Outlook skill nor any rules file records that, and `data-table.md` refuses it for
  body rows. The epic ships the header tier as standard table markup under #150's posture, and
  a real Outlook render is owed before it enters `data-table.md` as fact.
- **A cell note is the existing `[^n]` marker, not a `Cell.note` field.** One spelling for
  "a note is called here"; a second is the drift #117 was built to end.
- **The lint rule lands with the markup (#223), not with the fixture.** #150's lesson: a guard
  that ships later leaves a window the defect walks through.
- **No `epic` label or type exists.** Kept the house convention: `Epic:` title, `enhancement`,
  children typed `Task`. Templates' `sub` tags kept; only my own values avoid angle brackets.
