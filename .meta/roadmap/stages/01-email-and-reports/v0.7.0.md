# version: v0.7.0
status: planned

## Goals
- Roadmap epic 1.2: declared data inputs on a `Report`.
- Stale data refused at build time.
- Every figure carries its source and as-of date into the document, so a number can be
  traced back.

## Objectives / acceptance
- A data input older than its declared freshness raises a named error before rendering.
- Every figure that came from a declared input can be listed with its source and as-of
  date from the built document, and a test asserts the list for a reference report.
- The core still installs with Jinja2 alone; any data-frame support stays behind `[data]`.
