# version: v0.6.0
status: planned

## Goals
- Roadmap epic 1.1: a `Report` with typed, validated parameters (as-of date, universe,
  client) and a `build()` that returns anything renderable.
- A run CLI, `python -m pyhermes.run report.py --as-of 2026-10-30`, grown out of
  `pyhermes.check`'s target loading.

## Objectives / acceptance
- A bad parameter raises `ValidationError` at construction, never at render, per the
  hard constraint.
- The same report run twice with the same parameters and data produces identical bytes.
- `build()`'s return type admits a future content-model object without a breaking change,
  stated in the module's docstring and covered by a test.
- One reference report from v0.3.0 is ported to a `Report` and runs from the CLI.
