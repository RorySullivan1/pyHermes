# version: v0.4.0
status: in-progress

## Goals
- Roadmap epic 0.3: rename the project to **octavo** (owner's decision, 2026-10-29). The PyPI
  name `pyhermes` and the import root `pyhermes` both belong to Allegro's Hermes message-broker
  client (0.7.1), so publishing as-is is impossible and installing both would overwrite one.
- Rename the distribution and the import root (`pyhermes` to `octavo`) everywhere: the package,
  templates' resource lookups, tests, `qa/`, examples, drafts, `reference/`, the manual, the
  README, CLAUDE.md, the rules files and the agents scoped to the package.
- Keep history readable: session logs, archived decisions and closed issues keep the old name,
  as #248 did for `svc`.

## Objectives / acceptance
- The wheel's only top-level package is `octavo`, and `import octavo` renders an email from the
  wheel and the sdist in clean venvs (CI's `wheel` job).
- No `pyhermes` reference remains outside the memory's session logs and archive, enforced by a
  test the way `test_distribution.py` holds `svc` out.
- Every golden is byte-identical unless the name itself is rendered, and any golden diff is
  shown to be the name alone.
- The full suite, ruff, ruff format and mypy pass; the prose baseline does not grow.
- The GitHub repository's rename is the owner's call, recorded in the roadmap either way.
