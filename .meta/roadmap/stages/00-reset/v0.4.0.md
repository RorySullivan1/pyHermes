# version: v0.4.0
status: planned

## Goals
- Roadmap epic 0.3: the first public release on PyPI.
- A versioning and deprecation policy, and a changelog.

## Objectives / acceptance
- `pip install pyhermes` from PyPI in a clean venv renders an email (the `wheel` CI job's
  check, against the published artefact).
- The library ships under MIT, per the owner's open-core decision; the README states that the
  render service and any hosted product are licensed separately.
- `CHANGELOG.md` exists in Keep a Changelog form, and the deprecation policy says how long a
  public name survives once deprecated.
