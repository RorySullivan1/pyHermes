## Goals
- Roadmap epic 0.2: name three real reports as the acceptance fixtures for every stage: a
  daily email note, a long-form research report, a product tri-fold.
- Measure today's time from data to a sent note as the speed baseline.

## Objectives / acceptance
- Each reference report has a named owner, a written spec (audience, cadence, sections,
  data inputs) and a build script that renders today, committed under one directory.
- The benchmark is a documented, repeatable procedure with today's number recorded beside
  it, so every later gate can re-run it.
- The three reports render in CI as part of the suite.
